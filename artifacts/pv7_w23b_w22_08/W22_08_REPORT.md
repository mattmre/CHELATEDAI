## Departures from the preregistration

- Scope rule: 'declared scope equals the family's shared scope' is implemented as: the unit scope is the intersection of the candidate lists' declared scopes (or the F-PV7 stratum), a list enters if its declared scope covers the unit scope, and findings outside the unit scope are dropped and logged.
- F-PV7 strata contain bundle ordinals only. XC (cross-cutting) findings are reported descriptively and enter no stratum estimate.
- F-R5 scopes are textual ('Draft v3 whole, 27 bundles'); all four lists are assigned B1-B27 + XC. r5_grok reviewed the whole draft but re-hashed only 7 manifests; that is treated as a method limit, not a scope change.

- Chao2 variance uses the A=(k-1)/k scaled incidence form (Chao 2005); the preregistration names only 'Chao's (1987) log-normal interval'. For K3 a non-converged log-linear model, or one with a boundary estimate (a parameter |beta| > 15, i.e. the MLE does not exist because a capture-history margin is empty), is treated as non-finite. This changes K3 for F-PV7 non-gating units and for F-W14 (boundary on the grok*sol, neon*sol and sol*sonnet interaction models; without this rule F-W14 K3 would pass); F-W14 already fails K2, so no verdict changes.
