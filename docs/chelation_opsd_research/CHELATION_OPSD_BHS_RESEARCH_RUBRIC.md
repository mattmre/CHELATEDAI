# BHS Research Scoring Rubric for CHELATION + OPSD Program

**Purpose**: Apply the same Brutal Honesty v3.3 standards used in the main repo to this research program itself. Every loop and major deliverable will be scored for honesty, evidence quality, completeness, and practicality.

---

## Scoring Dimensions (Each out of 20)

1. **Evidence Quality** (0-20)
   - 20 = Strong runtime/reproducible evidence or clear, testable implementation path with no "path exists" overclaim.
   - 10 = Solid reasoning + some empirical or code artifacts.
   - 0-5 = Mostly theoretical or "we can do X" without mechanism.

2. **Honesty & Gap Exposure** (0-20)
   - Full L1-L13 taxonomy applied. Weaknesses, Carried Debt, and scope limitations explicitly called out rather than minimized.

3. **Completeness for the Loop** (0-20)
   - All major relevant angles for that loop explored (literature, code, edge cases, variants, risks).

4. **Practicality & Testability** (0-20)
   - The output can actually be implemented and evaluated in the repo with reasonable effort. Clear path to experiments.

5. **Leverage & Novelty** (0-20)
   - Combines OPSD ideas with CHELATEDAI's specific context in a high-leverage way (not generic advice).

**Total BHS Research Score** = Sum / 100

**BHS Research Tier**:
- 95–100: Exceptional (rare)
- 85–94: Strong (target for most loops)
- 70–84: Acceptable but needs improvement
- <70: Requires remediation before proceeding

---

## Loop-End BHS Self-Assessment Template

At the end of each loop, the Synthesis Agent + Integration Lead will produce:

- BHS_SELF_DRAFT score (0-100)
- Honest strengths
- Major weaknesses / gaps exposed
- Carried Debt items for future loops
- Specific actions to improve the score before the next loop

This mirrors the exact BHS process used for Wave 0 remediation in the main repo.
