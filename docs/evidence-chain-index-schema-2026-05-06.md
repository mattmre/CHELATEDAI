# Evidence Chain And Index Schema

Date: 2026-05-06

Purpose: document the generated JSON contracts for default-promotion evidence-chain summaries, cross-artifact evidence indexes, and freshness audits.

## `default_promotion_evidence_chain`

Generated by:

```bash
python run_default_promotion_evidence_chain.py --output-dir experiment_runs/default-promotion-evidence-chain/latest
```

Default path:

```text
experiment_runs/default-promotion-evidence-chain/latest/evidence_chain_summary.json
```

Fields:

| Field | Type | Meaning |
| --- | --- | --- |
| `record_type` | string | `default_promotion_evidence_chain` |
| `output_dir` | string | root directory for linked evidence outputs |
| `chain_passed` | boolean | validation and linkage-audit commands completed without command-level failure |
| `review_allowed` | boolean | preflight says default-promotion review may start |
| `default_change_allowed` | boolean | default change decision; currently false unless future preflight tooling allows otherwise |
| `command_failures` | string array | command-level failures in the evidence chain |
| `preflight_blockers` | string array | fail-closed blockers from default-promotion preflight |
| `artifacts` | object | paths to validation, audit, repeat-decision, and preflight artifacts |
| `summary_path` | string | path to this chain summary |

Interpretation:

- `chain_passed: true` and `review_allowed: false` is a valid no-default-change outcome.
- `chain_passed: false` means the evidence run itself failed and must be debugged before interpreting promotion readiness.

## `cross_artifact_evidence_index`

Generated by:

```bash
python generate_evidence_index.py --root experiment_runs --output experiment_runs/evidence-index/latest/evidence_index.json
```

Default path:

```text
experiment_runs/evidence-index/latest/evidence_index.json
```

Top-level fields:

| Field | Type | Meaning |
| --- | --- | --- |
| `record_type` | string | `cross_artifact_evidence_index` |
| `root` | string | scanned experiment root |
| `limit_per_type` | integer | maximum records retained per artifact type |
| `summary` | object | compact latest-status and count summary |
| `artifacts` | object | artifact-type keyed record lists |
| `output` | string | path where the index was written |

`summary` fields:

| Field | Type | Meaning |
| --- | --- | --- |
| `artifact_counts` | object | count of indexed records per artifact type |
| `latest_review_allowed` | boolean or null | latest indexed preflight review status |
| `latest_preflight_blockers` | string array | blockers from the latest indexed preflight |
| `latest_chain_passed` | boolean or null | latest indexed evidence-chain pass state |

Indexed artifact record fields:

| Field | Type | Meaning |
| --- | --- | --- |
| `path` | string | artifact path |
| `record_type` | string or null | source artifact record type |
| `modified_at` | number | filesystem modification time |
| `passed` | boolean or null | validation/audit/chain pass state when available |
| `review_allowed` | boolean or null | preflight review status when available |
| `promotion_ready` | boolean or null | promotion decision state when available |
| `decision` | string or null | source decision label when available |
| `blockers` | string array | source blockers when available |

## `evidence_index_freshness_audit`

Generated by:

```bash
python audit_evidence_index_freshness.py --index experiment_runs/evidence-index/latest/evidence_index.json --output experiment_runs/evidence-index/latest/freshness_audit.json
```

Fields:

| Field | Type | Meaning |
| --- | --- | --- |
| `record_type` | string | `evidence_index_freshness_audit` |
| `index` | string | audited index path |
| `passed` | boolean | no blockers found |
| `blockers` | string array | fail-closed blocker labels |
| `warnings` | string array | non-blocking malformed-entry warnings |
| `checked_path_count` | integer | indexed paths checked |
| `missing_paths` | string array | indexed paths that no longer resolve |
| `stale_paths` | string array | indexed artifacts newer than the index |
| `output` | string | optional audit output path |

Blockers:

| Blocker | Meaning |
| --- | --- |
| `evidence_index_missing_or_unreadable` | index file is absent or cannot be parsed |
| `evidence_index_artifacts_not_object` | index `artifacts` field has the wrong shape |
| `indexed_artifact_paths_missing` | at least one indexed source artifact cannot be found |
| `evidence_index_stale` | at least one indexed source artifact is newer than the index |

## Dashboard Surfaces

The dashboard reads these contracts through:

- `/api/evidence_index`
- `/api/evidence_chain_history`
- `/api/preflight_history`
- `/api/validation_history`
- `/api/campaign_history`

Dashboard ingestion is read-only. Regenerate artifacts with the CLI commands above before relying on displayed freshness or promotion-review status.
