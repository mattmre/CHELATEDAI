2. Publish updates atomically and validate legal transitions.
3. Render legacy artifacts as unknown, not running; add stale/interrupted/completed browser cases.

**AC1:** each rendered status is backed by manifest state. **AC2:** completed/stale/interrupted remain distinct after restart. **AC3:** impossible transitions/artifacts are rejected.
