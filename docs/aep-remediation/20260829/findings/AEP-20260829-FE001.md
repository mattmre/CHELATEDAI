## Defect evidence

Bearer auth is checked before routing even the HTML. Normal browser navigation cannot attach that header, and client fetches never add it. Real token-enabled HTTPServer probe: `/dashboard/` without header 401, with header 200; `/api/summary` without header 401; authorized request reached the handler. Meanwhile 67 dashboard unit tests pass with 2 skips.

import json, threading, urllib.error, urllib.request
from http.server import HTTPServer
import dashboard_server as d
d.DASHBOARD_TOKEN = "audit-token"
srv = HTTPServer(("127.0.0.1", 0), d.DashboardHandler)
thr = threading.Thread(target=srv.serve_forever, daemon=True); thr.start()
base = f"http://127.0.0.1:{srv.server_port}"
def get(path, token=None):
    req = urllib.request.Request(base + path)
    if token: req.add_header("Authorization", "Bearer " + token)
    try:
        with urllib.request.urlopen(req, timeout=5) as res: return res.status
    except urllib.error.HTTPError as exc: return exc.code
try:
    rows = {"page_no_header": get("/dashboard/"), "page_bearer": get("/dashboard/", "audit-token"), "api_no_header": get("/api/summary")}
    print(json.dumps(rows, sort_keys=True))
    assert rows == {"page_no_header": 401, "page_bearer": 200, "api_no_header": 401}
finally:
    srv.shutdown(); srv.server_close(); thr.join(timeout=5)

Expected current evidence: `do_GET` authorizes before `/dashboard/`, `_is_api_authorized` accepts only Bearer, browser fetch calls contain no Authorization bootstrap, the unit suite remains green (67 pass, 2 skip), and the real-handler probe prints `{"api_no_header": 401, "page_bearer": 200, "page_no_header": 401}`. The sealed raw run is `../http-auth-probe-receipt.txt`.

Root cause: API-client bearer validation was treated as a complete browser session design.

1. Define a threat model and implement a browser credential bootstrap (prefer login to HttpOnly/SameSite cookie) or formally remove browser remote mode.
2. Centralize authenticated fetch and explicit 401 rendering; avoid tokens in HTML, query strings, or persistent JS storage.
3. Add real browser E2E for page, API, expiry/logout, and non-loopback configuration.

**AC1:** supported protected navigation loads without manually injected headers. **AC2:** protected API data loads without token disclosure. **AC3:** missing/expired credentials produce an explicit login/error state, never empty data. Verification: ephemeral server plus browser network assertions. Dependencies: coordinate FE006 response handling.
