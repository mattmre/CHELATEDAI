## Defect evidence

Backup/unlink occurs only when the nesting stack is empty. An inner `isolated_adapter_state` therefore sees and can mutate the outer context file, and it has no per-level state to restore. Exact head and [review thread](https://github.com/mattmre/CHELATEDAI/pull/257#discussion_r3367630942) were opened.

Copy-paste inspection:

```powershell

gh api repos/mattmre/CHELATEDAI/pulls/comments/3367630942 --jq '[.path,.line,.body]'
```

Expected current evidence: backup/unlink is guarded by the empty-stack/outermost condition; the review describes inner scope visibility and missing per-level restoration.

Root cause: outermost-only lifecycle for a context manager whose contract is per-scope isolation.

1. Backup/unlink at every nesting level and push a per-level backup-or-absent marker.
2. Restore each level in `finally`; remove global stack only after outermost exit.
3. Test normal and exception nesting with content hashes.

**AC1:** inner scope starts isolated. **AC2:** outer state returns after inner exit. **AC3:** original pre-context bytes return after nested exceptions. Verification: `python -B -m unittest test_benchmark_utils` plus a real nested temp-file trace. Dependencies: none.
