## Defect evidence and commands

The protocol defines a control that removes station permutations while retaining the same factors and arithmetic budget. The implementation encodes/corrupts the target with `ordered_parameters` and changes only the decoder to `orderless_parameters`. The control therefore decodes an incompatible encoding rather than evaluating matched data generated without permutations.

## Root cause and atomic fix steps

The control is implemented as a decoder-only ablation, while the protocol specifies an encoding/decoding ablation.

1. Construct an independent no-permutation composite with `orderless_parameters` before corruption.
2. Decode that composite with the same orderless parameters and retain matched random/corruption budgets.
3. Regenerate the frozen vectors/results and invalidate the current ordered-binding gate result; do not lower the threshold to retain a pass.
4. Add a regression that proves encoder and decoder parameter identities match within each arm and that the two official run IDs use the intended control.
