## Defect evidence and commands

`enable_adapter_routing()` registers arbitrary centroid widths without comparing them with `self.vector_size` or with one another. The engine reports routing enabled, but the first real selection fails inside vector math.

```powershell
$probe = @'
from unittest.mock import MagicMock
from antigravity_engine import AntigravityEngine
engine = object.__new__(AntigravityEngine)
engine.logger = MagicMock()
engine.vector_size = 4
engine.adapter = object()
engine.enable_adapter_routing([("bad", [1.0, 0.0], object())])
print("enabled", engine._adapter_router is not None, "engine_dim", engine.vector_size)
try:
    engine._adapter_router.select([1.0, 0.0, 0.0, 0.0], fallback=lambda: engine.adapter)
except Exception as exc:
    print(type(exc).__name__ + ": " + str(exc))
'@
$probe | python -B -
python -B -m unittest test_antigravity_engine -v
```

Expected current evidence: routing reports enabled for engine dimension four, followed by a NumPy shape-alignment `ValueError` for the two-dimensional centroid. Registration does not fail atomically.

## Root cause and atomic fix steps

The generic router has no declared vector-space contract, and engine integration treats successful object construction as readiness.

1. Give `AdapterRouter` an immutable expected dimension at construction.
2. Validate every centroid for numeric type, finiteness, nonzero norm, and exact dimension before mutating the route table.
3. Validate the entire route batch before assigning `_adapter_router`; on any error, preserve the previous router and emit no enabled event.
4. Add mixed-width, nonfinite, zero-vector, bad-batch rollback, and valid routing tests through the engine path.

## Acceptance criteria

- **AC1:** the exact incompatible route is rejected during enablement with a typed configuration error.
- **AC2:** failed registration leaves the prior routing state unchanged and produces no enabled event.
- **AC3:** all accepted routes match the engine query dimension and can complete selection without shape failures.
