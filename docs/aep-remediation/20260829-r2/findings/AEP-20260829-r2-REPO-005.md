## Defect evidence and commands

The loader sorts reports newest-first, catches parse/read failures, and silently continues. When the newest record is malformed, the next older passing record becomes `reports[0]` and therefore `latest_passed: True`; the returned shape has no indication that newer state could not be read.

```powershell
$probe = @'
import json, os, tempfile
from pathlib import Path
from dashboard_server import load_validation_history
with tempfile.TemporaryDirectory() as td:
    root = Path(td)
    old = root / "old" / "validation_summary.json"
    new = root / "new" / "validation_summary.json"
    old.parent.mkdir(); new.parent.mkdir()
    old.write_text(json.dumps({"passed": True, "command_count": 1}), encoding="utf-8")
    new.write_text('{"passed":', encoding="utf-8")
    os.utime(old, (1, 1)); os.utime(new, (2, 2))
    result = load_validation_history(str(root))
    print({
        "loaded_reports": len(result["reports"]),
        "reported_total": result["summary"]["total_reports"],
        "latest_passed": result["summary"]["latest_passed"],
        "passed": result["summary"]["passed"],
        "failed": result["summary"]["failed"],
        "has_error_surface": any(key in result for key in ("errors", "unreadable", "incomplete")),
    })
'@
$probe | python -B -
python -m unittest test_dashboard_server -v
```

Expected current evidence: one loaded/total report, `latest_passed: True`, one passed, zero failed, and `has_error_surface: False`, despite the newer unreadable record. Current handler tests pass without this ordering/failure case.

## Root cause and atomic fix steps

Unreadable evidence is modeled as absence, so the aggregate cannot distinguish “no newer report exists” from “newer report exists but could not be interpreted.”

1. Preserve every selected candidate as either a valid typed record or an explicit unreadable record with bounded diagnostics.
2. Compute latest state from the newest candidate, not the newest successfully parsed candidate; unreadable latest state must be `unknown/error`, never inherited green.
3. Add schema/version validation and expose counts for valid, unreadable, and truncated records.
4. Apply the same contract to campaign, preflight, and evidence-history loaders; add malformed-newest and transient-read tests.

## Acceptance criteria

- **AC1:** the exact probe reports the newest state as unknown/error and includes an unreadable-record count/path.
- **AC2:** an older passing report cannot make `latest_passed` true when a newer selected record is unreadable.
- **AC3:** valid empty history, unreadable history, and valid passing/failing history remain mechanically distinguishable through the API.
