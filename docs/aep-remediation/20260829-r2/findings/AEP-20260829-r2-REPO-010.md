## Defect evidence and commands

Each renderer hides its `*-loading` element before validating and formatting response fields. Its caller catches render exceptions and writes the error message back into that same hidden loading element. A malformed-but-successful response can therefore leave blank or partial content with no visible failure state.

```powershell
rg -n -A 48 -B 8 'async function loadTTS|function renderTTS|async function loadModelScope|function renderModelScope|async function loadPhaseC|function renderPhaseC' dashboard_server.py
rg -n 'tts-loading|ms-loading|phase-c-loading|renderTTS|renderModelScope|renderPhaseC' test_dashboard_server.py dashboard/index.html
if ($LASTEXITCODE -eq 1) { 'NO_CLIENT_TESTS' }
python -m unittest test_dashboard_server -v
```

Expected current evidence: each renderer sets the loading node to hidden before field rendering, while its catch block assigns failure text to that node without making it visible. No client regression test supplies a malformed successful response.

## Root cause and atomic fix steps

Loading and error are overloaded into one DOM element, and response validation begins only after the loading state has been removed.

1. Define response discriminants and validate all required fields before committing a rendered-success state.
2. Give each panel dedicated visible loading, empty, content, and error containers or one explicit state machine that controls visibility atomically.
3. On render failure, clear partial output and select visible error state; never write into a hidden carrier.
4. Add malformed numeric, missing field, wrong collection type, valid empty, retry, and successful render tests for all three panels.

## Acceptance criteria

- **AC1:** every malformed successful response produces a visible panel-scoped error and no misleading partial result.
- **AC2:** loading, empty, success, and error are mutually exclusive and testable for Phase C, Model Scope, and TTS.
- **AC3:** a subsequent valid retry moves cleanly from error to success without residual text or hidden current errors.
