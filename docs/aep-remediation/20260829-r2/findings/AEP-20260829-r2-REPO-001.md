## Defect evidence and commands

The checkpoint ID contains only a sanitized name and wall-clock time to one second. Directory creation uses `exist_ok=True`, and the second `copy2` overwrites the first checkpoint's `adapter_weights.pt` while metadata appends a second row with the same ID.

```powershell
python -B -c "import tempfile; from pathlib import Path; from checkpoint_manager import CheckpointManager; td=tempfile.TemporaryDirectory(); root=Path(td.name); adapter=root/'adapter.pt'; m=CheckpointManager(root/'checkpoints'); adapter.write_bytes(b'FIRST'); first=m.create_checkpoint('same',adapter); adapter.write_bytes(b'SECOND'); second=m.create_checkpoint('same',adapter); rows=m.list_checkpoints(); stored=(m.checkpoint_dir/first/'adapter_weights.pt').read_bytes(); print({'first_id':first,'second_id':second,'same_id':first==second,'metadata_rows':len(rows),'row_ids':[r['checkpoint_id'] for r in rows],'stored_bytes':stored.decode()}); td.cleanup()"
python -m unittest test_checkpoint_manager -v
```

Expected current evidence: both immediate IDs are identical; two catalog rows share that ID; stored bytes are `SECOND`, proving `FIRST` was destroyed. The existing 32 tests pass without this collision case.

## Root cause and atomic fix steps

Wall-clock seconds are treated as unique identity, and an existing destination is treated as a valid checkpoint directory.

1. Generate collision-resistant IDs using readable time plus a random/monotonic suffix.
2. Create staging and final directories with no-replace semantics; bounded retry may only use a freshly generated ID.
3. Reject duplicate IDs before catalog commit and preserve the winner on any collision.
4. Add frozen-clock same-name, preexisting-destination, and concurrent-creator tests.

## Acceptance criteria

- **AC1:** two immediate same-name checkpoints have distinct IDs and independently restore `FIRST` and `SECOND`.
- **AC2:** a preexisting ID/directory is never overwritten or adopted.
- **AC3:** concurrent creators produce unique catalog rows with exact hashes, or a loser fails before touching the winner.
