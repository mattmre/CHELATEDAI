## Defect evidence and commands

`_save_metadata` directly writes the live JSON, catches every exception, prints, and returns success to its caller. `create_checkpoint` then prints and returns an ID. A fresh manager silently treats unreadable/corrupt metadata as an empty catalog, leaving acknowledged bytes undiscoverable and unrestorable.

```powershell
python -B -c "import tempfile; from pathlib import Path; from checkpoint_manager import CheckpointManager; td=tempfile.TemporaryDirectory(); root=Path(td.name); adapter=root/'adapter.pt'; adapter.write_bytes(b'valid-adapter-bytes'); m=CheckpointManager(root/'checkpoints'); m.metadata_path.mkdir(); cp=m.create_checkpoint('probe',adapter); print({'returned_id':cp,'checkpoint_bytes_exist':(m.checkpoint_dir/cp/'adapter_weights.pt').is_file(),'metadata_is_directory':m.metadata_path.is_dir()}); fresh=CheckpointManager(root/'checkpoints'); print({'fresh_checkpoint_count':len(fresh.list_checkpoints()),'restore_result':fresh.restore_checkpoint(cp,root/'restored.pt'),'restored_exists':(root/'restored.pt').exists()}); td.cleanup()"
```

Expected current evidence: output includes `ERROR: Failed to save checkpoint metadata`, then a false `Created checkpoint`; bytes exist, but a fresh manager lists zero checkpoints, restore returns false, and no restored file exists.

## Root cause and atomic fix steps

Checkpoint-byte publication and catalog persistence are not one transaction; load/write failures are converted into empty/success state.

1. Canonically encode metadata to a same-directory temporary file; flush/fsync it, atomically replace, and fsync the directory. Propagate every failure.
2. Stage checkpoint bytes privately and publish/catalog through a recoverable transaction or journal.
3. On load, distinguish absent metadata from corrupt/unreadable metadata; fail closed or recover through a verified journal, never silently reset.
4. Prevent `SafeTrainingContext` admission unless the checkpoint is durably cataloged and independently restorable.

## Acceptance criteria

- **AC1:** forced metadata write failure raises, emits no success ID/message, and leaves no public checkpoint.
- **AC2:** every injected crash point yields either the old complete catalog or the new complete catalog with matching bytes—never a truncated/empty reset.
- **AC3:** after restart, every acknowledged checkpoint restores by ID/hash; orphan stages are diagnosed but never accepted.
