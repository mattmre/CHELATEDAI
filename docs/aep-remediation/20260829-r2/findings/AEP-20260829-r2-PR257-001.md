## Root cause and atomic fix steps

A nonessential research/telemetry hook executes inside the primary exception path without its own nonthrowing boundary.

1. Capture the primary exception/traceback before invoking any secondary hook.
2. Isolate the hook in a narrowly typed nonthrowing telemetry boundary; record hook failure without replacing the primary cause.
3. Re-raise the original exception with its traceback intact.
4. Add hostile enabled-hook, disabled-hook, and enabled-success tests through `run_block_graph`.
