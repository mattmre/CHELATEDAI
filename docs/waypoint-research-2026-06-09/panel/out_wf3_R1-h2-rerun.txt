## (4) Gotchas

```powershell
# Preflight (fail fast if offline cache incomplete)
$env:HF_HUB_OFFLINE="1"; $env:HF_DATASETS_OFFLINE="1"; $env:TRANSFORMERS_OFFLINE="1"
python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('sentence-transformers/all-MiniLM-L6-v2'); SentenceTransformer('all-mpnet-base-v2'); print('models ok')"
python -c "from datasets import load_dataset; load_dataset('mteb/scifact', 'default'); load_dataset('mteb/nfcorpus', 'default'); print('datasets ok')"
```

- **`CHELATED_RUN_REAL_MODEL_TESTS=1` is irrelevant** to this driver (unittest gate only).
- **Do not use bash-style** `HF_HUB_OFFLINE=1 python ...` in PowerShell — use `$env:...` as above.
- Seeds/conditions/budget **not CLI-overridable** — wrong matrix only if you edit the module.
- **Overwrites** existing `main/`, `budget/`, `budget-confirm/`, manifest, and both `docs/drift-recovery-swap-*-results-2026-06.md`.
- **Expect C3a change only** after H1: shared baseline with C0; final NDCG + budget table shift slightly. If C3a baseline ≠ C0/C2/C2O/C4a on NFCorpus, fix regressed.
- Device auto: `_detect_device()` → `cuda` if torch sees GPU; no `--device` flag on swap campaign CLI.
- Large per-run JSON artifacts; disk + git size if force-adding.
- Best budget **re-selected** from seed-42 grid (SciFact historically **2000/0.10**; NFCorpus **30/0.01**); confirm phase uses whatever wins this re-run.
- Sequential only; leave VRAM free (kill competing torch jobs).
- Closure checklist: both commands green → verify C3a baseline equals peers → commit regenerated markdowns (+ optional force-add manifests) → close CD-H1-01 → **manually** patch paper §5.
