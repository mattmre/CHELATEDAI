## 2. Core contracts and harness reuse

### Shared data contracts

`contracts.py` defines:

- `RetrievalCase`
  - query/document IDs
  - source/drifted queries
  - target/old-space queries
  - cached old documents
  - optional oracle queries/documents
  - qrels
  - dataset/model/projection fingerprints

- `ExperimentSplit`
  - fixed evaluation IDs
  - anchor-pool IDs
  - nested anchor prefixes
  - split hashes

- `AnchorPairs`
  - paired source and target embeddings
  - no evaluation qrels

- `PerQueryRecord`
  - protocol, regime, dataset, condition, seed, method, query ID
  - floor/oracle/method NDCG@10
  - top-11 IDs and scores
  - recovery numerator and denominator metadata

- `RunManifest`
  - repo and harness SHAs
  - protocol SHA-256
  - model revisions/cache hashes
  - dataset and split hashes
  - every component seed
  - environment and exact command

### Method interfaces

Two interfaces are required because hubness methods operate on scores, not query vectors:

- `QueryAdapter.fit(AnchorPairs, FitResources) -> FittedQueryAdapter`
- `FittedQueryAdapter.transform(queries, RoutingContext) -> corrected_queries`
- `ScoreTransform.fit(CorpusView, AnchorPairs) -> FittedScoreTransform`
- `FittedScoreTransform.rank(queries, corpus, k) -> Rankings`

`MethodRunner` composes either interface into the same `PerQueryRecord` output.

No method may receive evaluation qrels during `fit`. Hyperparameter selection uses a separate anchor-validation partition and is frozen in the preregistration.

### `harness_bridge.py`

This is the only module allowed to import the merged harness.

Principal functions:

- `load_case(spec) -> RetrievalCase`
  - wraps `load_mteb_data`

- `build_upgrade_case(spec) -> RetrievalCase`
  - wraps `QueryEncoderDrift`

  - wraps `select_road_course_slice`

- `evaluate_legacy_method(name, case, split, config) -> list[PerQueryRecord]`

## 3. D1 — Paper statistics and correction plan

### Bootstrap implementation

`stats/paired_bootstrap.py` provides:

- `bootstrap_method_metrics(records, config)`
- `bootstrap_contrast(records, lhs, rhs, config)`
- `bootstrap_seed_aggregate(records, config)`
- `validate_bootstrap_inputs(records)`

For each bootstrap draw, resample query IDs with replacement and compute:

\[
R_m^{(b)}
=
\frac{\overline{N}_{m}^{(b)}-\overline{N}_{floor}^{(b)}}
{\overline{N}_{oracle}^{(b)}-\overline{N}_{floor}^{(b)}}.
\]

This is a ratio of resampled query means, not a mean of per-query recovery ratios.

Rules:

- 10,000 deterministic paired-query draws.
- Same query draw for floor, oracle, and every compared method.
- 95% percentile CI for NDCG, recovery, ΔNDCG, and Δrecovery.
- Never clip recovery or its denominator.
- Mark a resample invalid if `oracle − floor ≤ ε`.
- If more than 1% of draws are invalid, report recovery as unstable and block the claim.
- Centered bootstrap null distribution supplies contrast p-values.
- `multiple_testing.py` applies Holm correction to preregistered families.

For five-seed results, evaluation IDs stay fixed. Average each query’s paired delta across seeds, bootstrap queries, and separately enforce the all-five-seeds sign rule. This avoids treating seed/query combinations as independent observations.

## 4. D2 — Crossover harness

### Regime-U

`regimes/upgrade.py` uses:

- old MiniLM document cache;
- projected mpnet/bge query embeddings from `QueryEncoderDrift`;
- paired old/new anchor queries;
- new-encoder query/document embeddings for the oracle;
- one fixed evaluation set across all seeds and methods.

Projection seed and feasible dataset slice are fixed. The five experimental seeds vary anchor ordering, optimizer initialization, routing, and synthetic choices—not the evaluation queries.

### Regime-C

`regimes/synthetic_collapse.py` provides:

- `fit_reference_clusters(documents, k=16, training_ids)`
- `select_corrupted_clusters(clusters, n=8, seed)`
- `collapse_vectors(vectors, assignments, centroids, beta)`
- `build_collapse_case(base_case, beta, seed)`
- `validate_collapse_case(case)`

Preregister the corruption as:

\[
T_\beta(x)
=
\operatorname{normalize}\left((1-\beta)x+\beta\mu_{c(x)}\right)
\]

for eight selected clusters; unselected clusters are unchanged.

Conditions are `β ∈ {0.05, 0.10, 0.20}`. Tests must prove:

- `β=0` is identity.
- Only selected clusters move.
- Distance to the assigned centroid decreases monotonically with β.
- Cluster selection uses training data only.
- Each eligible cluster has minimum training and evaluation support.

Drifted queries are corrected toward the clean base space and retrieve against clean cached documents. Clean queries/documents define the oracle.

To make Regime-C explicitly favorable to the detector, apply the same corruption to a held-out diagnostic document sample. The topology/isomer machinery receives clean-cache statistics and corrupted diagnostic embeddings, but never the eight binary corruption labels or evaluation qrels.

### Methods

`methods/affine.py`:

- ridge affine map;
- mean-centered orthogonal Procrustes;
- canonical residual MLP from the merged harness.

`methods/local_adapters.py`:

- per-cluster ridge for `K={2,4,8,16}`;
- global ridge plus soft-routed rank-4 local residuals, fixed `K=16`;
- graph residual: global ridge plus cosine-kNN/Nadaraya–Watson residual interpolation.

Local ridge falls back to the global map if a cluster lacks the preregistered minimum sample count. Soft-routing temperature, graph neighbor count, and regularization are selected only on anchor validation and then frozen.

`methods/isotropy.py`:

- global mean centering;
- ZCA source-to-target alignment;
- all-but-the-top;
- CBIE.

All-but-the-top removes the common mean and selected dominant global PCs, matching the original method’s basic operation. CBIE clusters embeddings, centers each cluster, then removes cluster-specific dominant PCs; the original CBIE work explicitly uses local clustering and PCA rather than a global isotropy transform. [All-but-the-Top paper](https://openreview.net/pdf?id=HkuGJ3kCb), [CBIE paper](https://aclanthology.org/2021.acl-short.73.pdf).

`methods/hubness.py`:

- NICDM/local scaling;
- empirical mutual proximity/global scaling.

These rerank distances rather than pretending to be affine adapters. Local scaling uses neighborhood-dependent scale parameters; mutual proximity uses each point’s distance distribution. [JMLR source](https://www.jmlr.org/papers/v13/schnitzer12a.html).

`methods/bounded_chelation.py`:

- imports `topology_analyzer.py`, `isomer_detector.py`, and `stability_tracker.py`;
- exposes one cluster corruption score per cluster;
- applies the paper’s frozen controller schedule;
- enforces `α=0.05`;
- has no outcome-driven schedule or alpha tuning.

### Crossover execution

`d2/crossover.py` provides:

- `build_run_matrix(protocol)`
- `run_cell(cell)`
- `resume_run(run_id)`
- `aggregate_crossover(run_ids)`
- `evaluate_confirmatory_families(records)`

One cell is:

```text
regime × dataset × beta-or-upgrade × seed × method
```

Runs are atomic and restartable. Encoding/cache construction is separate from method evaluation.

Run ladder:

1. Smoke: reduced documents/queries, one seed, β=0.10.
2. Feasible: SciFact, NFCorpus, Quora subset; all methods, five seeds, all β.
3. Full Quora: only after the scale gate.

### Statistical and kill decisions

The middle corruption `β=0.10` is the confirmatory Regime-C condition. The other β values are robustness analyses and cannot rescue a failed primary test.

A comparison is a win only when all are true:

- Δrecovery ≥ 0.05.
- ΔNDCG@10 ≥ 0.02.
- Both 95% paired-query CIs exclude zero.
- Holm-adjusted `p < 0.05`.
- Delta has the same sign in all five seeds.

Primary chelation family:

```text
3 feasible datasets
× {CBIE, local scaling, mutual proximity}
× {ΔNDCG, Δrecovery}
= 18 Holm-corrected tests
```

Binding gates:

1. Detector gate: mean seed-level AUPRC must be at least 0.80 in every feasible `dataset × β` condition. CIs are reported.
2. Mechanism gate: at β=0.10, chelation must achieve a qualifying win against all three baselines on at least two of three datasets, with no significant loss on the third.
3. Failure of either gate kills chelation. No alpha sweep, detector redesign, alternative aggregation, or secondary-β rescue follows.

## 5. D3 — Recoverability estimator

### Input firewall

`certificate/contracts.py` defines `CertificateInput` containing only:

- paired source/target anchor embeddings;
- cached old documents;
- target-side anchor query rankings/scores;
- anchor count and provenance.

It explicitly excludes:

- fitted adapter parameters;
- corrected evaluation embeddings;
- evaluation qrels;
- observed recovery;
- oracle evaluation rankings.

A test must successfully run prediction after fitted-adapter artifacts are removed.

### Gram and margin features

`certificate/features.py` provides:

- `center_and_shrink_whiten(X)`
- `off_diagonal_gram(X)`
- `gram_distortion(source, target)`
- `query_margin_curve(queries, documents, k=10)`
- `extract_certificate_features(input)`

Features are deliberately small:

- normalized Frobenius Gram distortion;
- p50/p90/p99 rowwise Gram distortion;
- whitened Gram distortion;
- source/target effective rank and covariance condition number;
- anchor-count-to-rank ratio;
- boundary gap `score_10 − score_11`;
- minimum adjacent gap across ranks 1–11;
- margin survival curve on a fixed threshold grid.

### Conditional bound

`margin_bound.py` formalizes the defensible part:

For unit-normalized documents, if a corrected query has target-space error at most `ε`, every document score changes by at most `ε`. Therefore, a query whose minimum relevant ranking gap exceeds `2ε` preserves its top-10 ordering.

Gram distortion does not by itself prove such an `ε` for a nonlinear encoder upgrade. The proposed theorem work is:

- exact equality of centered, whitened paired Grams plus rank assumptions implies an affine relation up to an orthogonal factor;
- approximate equality yields an error bound multiplied by conditioning terms.

Until that proof and its assumptions are independently checked, it must be labeled a conditional proposition, not a certificate theorem.

### Calibrated predictor

`calibration.py` maps the prefitting feature vector to an error proxy:

\[
\widehat{\epsilon}
=
g(d_{Gram}, q_{90}, q_{99}, \kappa, n/r),
\]

with a monotone, low-capacity calibrator. The margin survival curve then produces an initial recoverability estimate:

\[
\widehat R = \Pr(m_q > 2\widehat\epsilon).
\]

A grouped conformal residual correction supplies a conservative lower prediction bound. `predictor.py` returns:

- point prediction;
- interval/lower bound;
- probabilities that recovery exceeds 0.70, 0.90, and 0.99;
- highest supported tier;
- OOD and abstention reasons.

Validation must group by `dataset × encoder-pair`; seeds and anchor counts from one scenario may not cross folds. Compare against constant-mean and margin-only baselines.

Certificate naming gate:

- Predictor must beat the constant baseline by at least 10% grouped-CV MAE.
- Spearman correlation with held-out recovery must exceed 0.60.
- Nominal 90% interval coverage must land in 85–95%.
- A tier is unsupported unless there are at least five independent scenarios on each side of its threshold.
- If these fail, ship “recoverability-estimator prototype,” not “certificate.”
- The 99% tier should be expected to abstain unless the run archive actually contains enough near-perfect independent cases.

## 2. Core contracts and harness reuse

### Shared data contracts

`contracts.py` defines:

- `RetrievalCase`

### Method interfaces

Two interfaces are required because hubness methods operate on scores, not query vectors:

- `QueryAdapter.fit(AnchorPairs, FitResources) -> FittedQueryAdapter`
- `FittedQueryAdapter.transform(queries, RoutingContext) -> corrected_queries`

- `FittedScoreTransform.rank(queries, corpus, k) -> Rankings`

`MethodRunner` composes either interface into the same `PerQueryRecord` output.

No method may receive evaluation qrels during `fit`. Hyperparameter selection uses a separate anchor-validation partition and is frozen in the preregistration.

Principal functions:

- `load_case(spec) -> RetrievalCase`

- `build_upgrade_case(spec) -> RetrievalCase`
  - wraps `QueryEncoderDrift`

- `select_feasible_slice(case, spec) -> RetrievalCase`
  - wraps `select_road_course_slice`

- `evaluate_legacy_method(name, case, split, config) -> list[PerQueryRecord]`
  - wraps the existing `evaluate_*` functions

- `canonical_ndcg(qrels, ranking, k=10)`
  - delegates to the merged `ndcg`

- `assert_harness_parity()`
  - proves that mean per-query results reproduce the merged aggregate evaluator

## 3. D1 — Paper statistics and correction plan

### Bootstrap implementation

`stats/paired_bootstrap.py` provides:

- `bootstrap_method_metrics(records, config)`
- `bootstrap_contrast(records, lhs, rhs, config)`
- `bootstrap_seed_aggregate(records, config)`
- `validate_bootstrap_inputs(records)`

For each bootstrap draw, resample query IDs with replacement and compute:

\[
R_m^{(b)}
=
\frac{\overline{N}_{m}^{(b)}-\overline{N}_{floor}^{(b)}}
{\overline{N}_{oracle}^{(b)}-\overline{N}_{floor}^{(b)}}.
\]

This is a ratio of resampled query means, not a mean of per-query recovery ratios.

Rules:

- 10,000 deterministic paired-query draws.
- Same query draw for floor, oracle, and every compared method.
- 95% percentile CI for NDCG, recovery, ΔNDCG, and Δrecovery.
- Never clip recovery or its denominator.
- Mark a resample invalid if `oracle − floor ≤ ε`.
- If more than 1% of draws are invalid, report recovery as unstable and block the claim.
- Centered bootstrap null distribution supplies contrast p-values.
- `multiple_testing.py` applies Holm correction to preregistered families.

For five-seed results, evaluation IDs stay fixed. Average each query’s paired delta across seeds, bootstrap queries, and separately enforce the all-five-seeds sign rule. This avoids treating seed/query combinations as independent observations.

### Anchor-count learning curve

`learning_curve.py` supplies:

- `make_nested_anchor_orders(anchor_pool, seeds)`
- `evaluate_anchor_curve(case, methods, counts, seeds)`
- `summarize_anchor_curve(records)`

Protocol:

- Counts: `{8, 16, 32, 64, 128}`.
- Five fixed anchor-order seeds: `{17, 29, 43, 71, 101}`.
- One fixed evaluation set.
- Each larger count is a prefix containing the smaller count.
- Ridge, residual MLP, and C3a use identical IDs at each point.
- Unsupported counts are `NA`; the evaluation set is never reduced to make a count fit.
- Plot point estimates, paired-query CI ribbons, and seed-level values.

## 4. D2 — Crossover harness

### Regime-U

`regimes/upgrade.py` uses:

- old MiniLM document cache;
- projected mpnet/bge query embeddings from `QueryEncoderDrift`;
- paired old/new anchor queries;
- new-encoder query/document embeddings for the oracle;
- one fixed evaluation set across all seeds and methods.

Projection seed and feasible dataset slice are fixed. The five experimental seeds vary anchor ordering, optimizer initialization, routing, and synthetic choices—not the evaluation queries.

### Regime-C

`regimes/synthetic_collapse.py` provides:

- `fit_reference_clusters(documents, k=16, training_ids)`
- `select_corrupted_clusters(clusters, n=8, seed)`
- `collapse_vectors(vectors, assignments, centroids, beta)`
- `build_collapse_case(base_case, beta, seed)`
- `validate_collapse_case(case)`

Preregister the corruption as:

\[
T_\beta(x)
=
\operatorname{normalize}\left((1-\beta)x+\beta\mu_{c(x)}\right)
\]

for eight selected clusters; unselected clusters are unchanged.

Conditions are `β ∈ {0.05, 0.10, 0.20}`. Tests must prove:

- `β=0` is identity.
- Only selected clusters move.
- Distance to the assigned centroid decreases monotonically with β.
- Cluster selection uses training data only.
- Each eligible cluster has minimum training and evaluation support.

Drifted queries are corrected toward the clean base space and retrieve against clean cached documents. Clean queries/documents define the oracle.

To make Regime-C explicitly favorable to the detector, apply the same corruption to a held-out diagnostic document sample. The topology/isomer machinery receives clean-cache statistics and corrupted diagnostic embeddings, but never the eight binary corruption labels or evaluation qrels.

### Methods

`methods/affine.py`:

- ridge affine map;
- mean-centered orthogonal Procrustes;
- canonical residual MLP from the merged harness.

`methods/local_adapters.py`:

- per-cluster ridge for `K={2,4,8,16}`;
- global ridge plus soft-routed rank-4 local residuals, fixed `K=16`;
- graph residual: global ridge plus cosine-kNN/Nadaraya–Watson residual interpolation.

Local ridge falls back to the global map if a cluster lacks the preregistered minimum sample count. Soft-routing temperature, graph neighbor count, and regularization are selected only on anchor validation and then frozen.

`methods/isotropy.py`:

- global mean centering;
- ZCA source-to-target alignment;
- all-but-the-top;
- CBIE.

All-but-the-top removes the common mean and selected dominant global PCs, matching the original method’s basic operation. CBIE clusters embeddings, centers each cluster, then removes cluster-specific dominant PCs; the original CBIE work explicitly uses local clustering and PCA rather than a global isotropy transform. [All-but-the-Top paper](https://openreview.net/pdf?id=HkuGJ3kCb), [CBIE paper](https://aclanthology.org/2021.acl-short.73.pdf).

`methods/hubness.py`:

- NICDM/local scaling;
- empirical mutual proximity/global scaling.

These rerank distances rather than pretending to be affine adapters. Local scaling uses neighborhood-dependent scale parameters; mutual proximity uses each point’s distance distribution. [JMLR source](https://www.jmlr.org/papers/v13/schnitzer12a.html).

`methods/bounded_chelation.py`:

- imports `topology_analyzer.py`, `isomer_detector.py`, and `stability_tracker.py`;
- exposes one cluster corruption score per cluster;
- applies the paper’s frozen controller schedule;
- enforces `α=0.05`;
- has no outcome-driven schedule or alpha tuning.

### Crossover execution

`d2/crossover.py` provides:

- `build_run_matrix(protocol)`
- `run_cell(cell)`
- `resume_run(run_id)`
- `aggregate_crossover(run_ids)`
- `evaluate_confirmatory_families(records)`

One cell is:

```text
regime × dataset × beta-or-upgrade × seed × method
```

Runs are atomic and restartable. Encoding/cache construction is separate from method evaluation.

Run ladder:

1. Smoke: reduced documents/queries, one seed, β=0.10.
2. Feasible: SciFact, NFCorpus, Quora subset; all methods, five seeds, all β.
3. Full Quora: only after the scale gate.

### Statistical and kill decisions

The middle corruption `β=0.10` is the confirmatory Regime-C condition. The other β values are robustness analyses and cannot rescue a failed primary test.

A comparison is a win only when all are true:

- Δrecovery ≥ 0.05.
- ΔNDCG@10 ≥ 0.02.
- Both 95% paired-query CIs exclude zero.
- Holm-adjusted `p < 0.05`.
- Delta has the same sign in all five seeds.

Primary chelation family:

```text
3 feasible datasets
× {CBIE, local scaling, mutual proximity}
× {ΔNDCG, Δrecovery}
= 18 Holm-corrected tests
```

Binding gates:

1. Detector gate: mean seed-level AUPRC must be at least 0.80 in every feasible `dataset × β` condition. CIs are reported.
2. Mechanism gate: at β=0.10, chelation must achieve a qualifying win against all three baselines on at least two of three datasets, with no significant loss on the third.
3. Failure of either gate kills chelation. No alpha sweep, detector redesign, alternative aggregation, or secondary-β rescue follows.
4. The non-chelation local-adapter experiment continues and is publishable even when chelation is killed.

## Principal risks

- **Statistical pseudo-replication:** fixed evaluation IDs, query-level pairing, seed-sign gate, grouped D3 validation.
- **Outcome-driven tuning:** immutable preregistration hash; anchor-only validation; secondary conditions cannot rescue primary failure.
- **Baseline underimplementation:** separate embedding and score-transform interfaces; CBIE and hubness methods follow their source definitions.
- **Recovery denominator instability:** never clip; block unstable cells.
- **Synthetic-regime favoritism:** disclose diagnostic document access and keep Regime-C claims separate from real upgrade claims.
- **Scale/OOM:** encode once, memory-map CPU arrays, batch top-11 retrieval, serialize GPU jobs, make full Quora optional.
- **Private harness API drift:** one bridge module and a mandatory parity test.
- **Ignored/local-only evidence:** explicitly track final sources and manifests before any “shipped” claim.
- **D3 overclaiming:** physics-informed low-capacity estimator, prefitting firewall, grouped holdouts, and default abstention when 90/99% support is absent.
