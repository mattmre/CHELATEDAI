## Prior art check (what actually anticipates you)

I verified the nearest 2023–2026 work. The briefing’s prior-art list is **correct and under-stated**, not overstated.

### Drift / upgrade alignment — fully anticipated

**Drift-Adapter** (EMNLP 2025, arXiv:2509.23471) is the same product problem: MiniLM-class → stronger model, Procrustes / low-rank affine / residual MLP, paired old/new embeddings, recovery vs full re-embed oracle. They report **95–99%** recall recovery in a mild regime (MLP best there) and already treat supervision count / sample size as the practical bottleneck. Severe drift (e.g. GloVe→MPNet-class) drops toward the ~70% band — same qualitative ceiling story as your 66–84% ridge band.

Direction differs (they map **new query → old index**; you map **old docs → new query space**), but that is an implementation dual of the same alignment task, not a new mechanism. Mechanism family = **anticipated**.

**Procrustes-Bounds** (arXiv:2510.13406) supplies the theory your “~linear ceiling” rests on: if pairwise dots are approximately preserved across two embedding models, there exists an orthogonal map with tight alignment error; empirically, **query-encoder upgrade + Procrustes** makes cross-model retrieval work and can even *gain* when the query model is stronger. That paper’s partial-upgrade setting is your arena written cleanly.

**QDC** (arXiv:2506.00037) is the trivial end of the spectrum: estimate mean query drift and subtract — constant translation, not even a full matrix.

**LlamaIndex-style linear adapters**, **relative representations** (Moschella et al. ICLR 2023), **vec2vec / universal geometry** (NeurIPS 2025 lineage): unsupervised or lightly supervised linear/affine space translation without inventing “correction posts.”

**Brutal bottom line on mechanisms:** bounded near-identity residual posts, living-bank anneal, prune/re-anneal, InfoNCE-vs-regression, and “MLP beats linear?” are all either classical or already benchmarked by Drift-Adapter. **There is no new corrector mechanism hiding in your positive path.** What you have that they do not emphasize as loudly is the **quantified loss to a one-line ridge map + the three evaluation hazards** — methodology and negative result, not invention.

### Within-model collapse / anisotropy — also not virgin

If the reframe pivots to anisotropy / hubness / “semantic collapse”:

- **Global whitening / ZCA / Soft-ZCA** (e.g. Soft-ZCA for code search, 2024–2025) is the standard baseline family for isotropy repair.
- Hubness reduction is a mature literature (distance transforms, local scaling, graph neighborhood cleanup) — not an open discovery that “local posts” invent.
- **Unsupervised homeostatic loops that should undo drift without a paired target** face the same **identifiability / unpaired domain-translation no-go** you already named as Hazard 2. That is not a loophole; it is a structural wall.

So P4 is “less tested *by you*,” not “unclaimed scientific territory.”

### Path-by-path brutality

**P1 — local vs global paired regression**  
Re-confirms more often than it surprises. If residual is mostly one global isometry/affine (Procrustes-Bounds regime), local maps are at best a mild residual smoother + variance reduction. A +2 NDCG recovery point is a blog post, not NeurIPS.  
**Only run this if you need a one-week kill-shot on “locality is the missing ingredient.”**

**P2 — relational / neighborhood correction**  
Only interesting path *inside* the upgrade arena. All of Drift-Adapter / Procrustes-Bounds / QDC are **point maps**. If the residual 16% of oracle gap is **neighborhood distortion** rather than **irreducible semantic mismatch** between MiniLM and mpnet, a graph regularizer or local isometry-on-edges could matter.  
Prior: most of that residual is **content the small model never represented** (capacity/training gap), not a missing kNN feature. So P2 is the romantic path and the most likely to re-confirm the linear ceiling.

**P3 — detection-gated hybrid**  
Does not create a new scientific object. Topology/isomer signals as **detectors** are closer to production monitoring (embedding drift detectors are already commercial literature) than to a groundbreaking corrector. Value is **operational**: fire expensive paired re-embed only on suspicious clusters. That is a solid systems finding if you measure **cost–recovery Pareto**, not if you claim a new geometry of mind.

**P4 — pivot arena**  
Only path that could revive a *ChelatedAI-shaped* story. But two landmines:

1. **Existence is not free.** “Long-lived stores develop heterogeneous semantic collapse” may be false or tiny under modern frozen encoders. Anisotropy often exists **at init / at train time**, not as a progressive store disease.
2. **Baselines will eat you.** Soft-ZCA / whitening / hubness reduction / re-embed-hot-docs / cross-encoder rerank are the real competitors. Beating “do nothing” is worthless; beating **global Soft-ZCA + optional full re-embed of top-k hubs** is the bar.

**Missed path (P0 / P5):**  
**P0 — Stop inventing correctors; publish the negative methodology.** Fair upgrade arena, three hazards, ridge ceiling, living-bank no-op, S1 dominated by re-embed. Built *on* Drift-Adapter as a **failure modes companion**. Odds of acceptance as Findings / workshop / short paper: **40–55%**. Odds of “exceptional groundbreaking”: **~0%**. This is the **highest EV scientific product you can ship without new miracles**.

**P5 (missed): capacity / model-gap residual analysis.** Decompose the 16% unrecovered gap into (a) linear-alignment residual, (b) nonlinear geometry, (c) rank/capacity. If (c) dominates, *no post-hoc corrector* of frozen MiniLM vectors can hit oracle — which **kills P2** and sharpens the paper. Cheap, high clarity.
