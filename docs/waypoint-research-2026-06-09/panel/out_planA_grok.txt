## 1. Where D2 gives false positives / false negatives

### False positives (fake wins)

| ID | Failure mode |
|---|---|
| **FP-A** | **Detector cosplay.** Corruption collapses 8/16 k-means clusters. Scoring AUPRC with features/labels from the *same* k-means recovers the injection knob, not retrieval risk. |
| **FP-B** | **Local ridge is the DGP.** Regime-C is piecewise centroid collapse; per-cluster ridge with matching K is near-optimal by construction. That is not a chelation win (and Drift-Adapter already showed synthetic local gains). |
| **FP-C** | **Baseline fishing.** Centroid collapse is CBIE/hubness’s toy. Beating a weak baseline after test-set HP search is selection bias. |
| **FP-D** | **Recovery points without absolute NDCG.** 5 recovery pts on a 0.03 gap is 0.0015 NDCG. Dual thresholds must apply to the **same bootstrap CI**, with a minimum oracle gap (e.g. ≥0.05) or the cell is underpowered. |
| **FP-E** | **Multiplicity.** 5 seeds × methods × β × K × datasets makes “same sign in 5 seeds” weak. Cap primary tests at ≤4; Holm the family. |

|---|---|

## 2. Where D1’s statistical fix falls short

**10k paired-query bootstrap is necessary and not sufficient.**

It buys CIs on fixed-split NDCG and on ridge−MLP / ridge−C3a deltas. It does **not** cover:

1. **Map uncertainty** — fit half is one `seed=42` permutation (`ladder_evalsplit.py`); bootstrap is conditional on a fixed W  
2. **Projection-seed uncertainty** — one `QueryEncoderDrift` seed  
3. **MLP optimization uncertainty** — one train ≠ capacity ceiling  
4. **A mathematical ceiling** — CIs around a plateau still do not make a ceiling  
5. **Held-out reconstruction** — ranking plateau ≠ MSE plateau  

**Concrete D1 holes in the assets:**

- **C3a as scalar** (`C3A = 0.1609`) vs self-contained maps → bootstrap on ridge−C3a is theater until per-query scores share one NDCG implementation  
- **Learning curve confounds** — C3a (query InfoNCE) and ridge (doc pairs) must not share a fake “n_anchors” x-axis; the +59 pt story is supervision type, not sample size  
- **n ≈ 600 pairs, d = 384** — cannot claim saturation toward Drift-Adapter’s ~20k regime  
- **Language is global** — abstract/intro/§5.5 still say “ceiling”; one §5.5 edit is not enough  
- **§3 is still a stub** — methodology paper fails without bound formula + adapter maps  
- **Repro is fake** — scripts are git-excluded with hardcoded `gpu-campaigns` paths  

**Artifact-first D1:** freeze `Do, Dor, Qd, qrels, fit_idx, per-query scores` once; all stats offline.

## 3. Is D3 well-posed or hand-wavy?

**Well-posed as a margin residual estimator. Hand-wavy as a “theorem / certificate / before fitting.”**

Solid core (Codex margin idea):

\[
m = q^\top y_r - q^\top y_j > \|q\|(\|e_r\|+\|e_j\|)
\]

⇒ order preservation under residual \(e = Y - g(X)\). From paired calibration docs + query margins, predict inversion rate → recovery bands.

**Hand-wavy if left as briefed:**

| Phrase | Problem |
|---|---|
| “theorem” | Gram distortion alone does not imply NDCG; top-k dependence breaks free theorems |
| “BEFORE fitting” | Affine residual **is** from fitting (or CV). Mean: before full re-embed / before committing corrector class |
| “70/90/99%” bins | Too few regimes; overfit unless leave-one-regime-out |
| “validate on existing runs” | Same-run calibration is circular; need held-out (bge / NFCorpus / n_anchor) |
| “certificate” | Needs empirical coverage of a proved lower bound; default name = **estimator** |

**Minimum non-hand-wavy D3:** cross-fitted residual + margin features → \(\hat R, \hat R_{lo}\); leave-one-regime-out; success bar (e.g. Spearman ≥ 0.7 or 80% three-way bin accuracy) **or** explicit failure note. **Depends on D1 packs, not D2.**
