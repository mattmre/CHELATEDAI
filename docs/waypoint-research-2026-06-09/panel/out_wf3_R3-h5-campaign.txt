### (4) Preregistered decision rule (H5 gate)

From `_post_bank_verdict` / PR #290:

```
living_bank_wins  iff
  C5, C5s, C5r all present
  AND mean_final_ndcg(C5) > mean_final_ndcg(C5s)   # living_beats_static
  AND mean_final_ndcg(C5) > mean_final_ndcg(C5r)   # living_beats_one_shot
```

- Metric: **mean final NDCG@10 over seeds** (strict `>`; **tie = loss**).
- **Not** vs `C3a`/`C4a`. Those are **absent** from default H5 conditions. C0/C2O are floor/ceiling **context only** — they do not enter the gate.
- H4 compound is **out of scope** for this verdict.

### (5) Gotchas + H2 ordering

```powershell
# Smoke (no GPU) before overnight:
python -m unittest test_post_bank_head_to_head -v
```

1. **`python run_drift_recovery_swap_campaign.py` ≠ H5.** Must use `run_condition_head_to_head` via `python -c`.
2. **No CLI for H5 / no `--compound-cycles`** on experiment or campaign parsers.
3. **Default budget 30/0.01** under-fit for C3a historically; H5 post-bank uses same defaults — interpret vs that.
4. **Datasets:** default SciFact only; multi-dataset needs repeated invocations.
5. **Offline:** set `HF_HUB_OFFLINE` / `HF_DATASETS_OFFLINE` / `TRANSFORMERS_OFFLINE`; cache must already hold MiniLM + mpnet + task data.
6. **Default report path** if you omit custom `report_md` is still `docs/drift-recovery-swap-results-2026-06.md` (swap default) — **override** or you clobber the swap doc with an H5 report.
7. **`compound_cycles` does not apply to C5/C5s/C5r** (different apply path; PR #291).
8. **H2 dependency:** H5 **does not load** H2/swap artifacts. It re-runs C0/C2O itself.  
   - **H2 is required** only for **CD-H1-01** (stale **C3a** numbers in swap result docs after H1 fix `5b2379b`).  
   - **Ordering:** H2 first if you care about paper §5 / C3a baselines; **not required** to start H5 numerics.  
   - H5 vs C3a/C4a comparison is **not** in the preregistered gate — add conditions yourself or run H2 separately and compare offline.

**Recommended GPU order if doing both:** H2 SciFact + NFCorpus (`run_swap_campaign` CLI) → H5 SciFact (`run_condition_head_to_head`) → optional H5 NFCorpus → optional H4 compound ablation.
