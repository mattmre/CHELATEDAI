## Track 1 — Model-swap arena (the real test; highest priority)

Synthetic geometric drift can't test the thesis: C2 trivially inverts it (oracle) and the
actuator has no supervision target. Model-swap drift fixes both.

- **PR-A1 — `DriftInjector.inject_model_swap_drift` + tests.** Drift = re-embed a
  `fraction` of corpus docs from `payload["text"]` with `all-mpnet-base-v2` (768-dim),
  project 768→384 via a **frozen seeded `DimensionProjection`**, L2-renormalize, upsert.
  Queries stay on MiniLM. Manifest records `swap_model`, `projection_seed`,
  `projection_checksum`, `affected_ids`, checksums, `injection_index`.
  **EVIDENCE (the sprint's central justification):** on a 50-doc in-memory corpus, (a) a
  measured NDCG drop after swap drift, AND (b) the **oracle-breaker assertion** — a
  frozen-MiniLM re-embed of the affected text does NOT restore the pre-drift vector
  (differs from both pre- and post-drift by a measurable margin). Determinism + manifest
  tests must run without mpnet present (inject a stub second-embedder via the backend
  abstraction); the real-model path may `skipUnless` cached.
- **PR-A2 — Anchor-supervision path (C3a/C4a) + held-out split.** Before drift, snapshot a
  seeded anchor set of (query, relevant-doc) pairs from qrels, **disjoint from the eval
  query set** (split by query id). At correction time, train the bounded adapter with
  InfoNCE (`engine.set_sedimentation_loss("infonce")`) so adapted drifted-doc vectors
  increase cosine sim to their anchor queries vs in-batch negatives. Wire C3a/C4a into the
  condition dispatch. Also apply P0/P1 mechanism fixes here so the actuator can fire:
  `use_quantization=True` in `_build_engine`, and drive `observe_annealing_drift` from the
  NDCG-drop-vs-baseline signal (the method accepts an explicit override). **EVIDENCE:** a
  real 2-cycle run where `should_correct=True` AND `correction_applied=True` AND correction
  norm > floor — i.e., the actuator that was dead in v1 now fires. If it will NOT fire after
  2 honest attempts, ship that as the documented finding and escalate (§8) — do not
  hand-force the trigger and call it closed-loop.
- **PR-A3 — Teacher-supervision path (C3b).** MiniLM-as-teacher via the existing
  `hybrid`/`offline` path. Smaller. Document explicitly that C3b shares information with C2.
- **PR-A4 — Calibration scout + campaign + results doc.** No new product code. Scout
  `fraction ∈ {0.3, 0.5}` for the 8–20% C0-drop band, then run {C0, C2, C3a, C3b, C4a} ×
  model_swap × seeds {42,1337,7}, `--max-queries 100 --sample-docs 1200 --cycles 12`.
  Output JSON adds `should_correct_count`, `correction_applied_count`, `mean_correction_norm`,
