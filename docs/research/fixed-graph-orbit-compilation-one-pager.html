Fixed-Graph Orbit Compilation

Can symmetry-related stochastic programs reuse one embedding on a fixed, sparse thermodynamic graph?

Construction

Let the hardware expose adjacency AH and Ising energy:

E0(z) = h0Tz + zTJ0z,   zi ∈ {−1,+1}.
PgTAHPg = AH,    Jg = PgTJ0Pg,    hg = PgTh0.
pg(z | Tgx) = p0(Pgz | x).

Each interface changes the logical frame and parameters while preserving the physical edge set and target distribution up to the declared symmetry.

For a cyclic family, one shared shift preserves relative phase:

φ′ℓ = φℓ + s (mod p),    φ′ℓ − φ′m = φℓ − φm (mod p).
Hypothesis: one embedded parent supports K related programs at Cshared ≈ C(F) + K·Cparams, rather than Cseparate ≈ K·C(F), with no material loss in sampling or routing quality.

Minimal experiment

  1. Build p = 7 or 11 cyclic factors on one degree-≤16 graph.
  2. Implement at least four related, semantically distinct interfaces.
  3. Fix the edge set; vary only Pg, hg, and Jg.
  4. Run in Torx/THRML and compare with matched controls.
  5. Remove views or edges and measure reconstruction degradation.

Controls and measures

Controls: separate embeddings, flat concatenation, one global phase, independent rotations, and topology-matched random factors.

Measures: distributional error, compilation and reconfiguration cost, pbits, couplers, auxiliaries, mixing, held-out routing accuracy, and partial-erasure recovery.

Decision rule

Continue only if the shared construction:

  1. preserves the target distribution within a declared bound;
  2. improves embedding or reconfiguration cost at matched resources;
  3. survives partial erasure better than flat controls; and
  4. does not reduce to relabeling, one global phase, or an equivalent flat code.
The phase coding and graph symmetries are established mathematics. The open question is whether their composition enables useful reuse of a fixed thermodynamic hardware embedding.
