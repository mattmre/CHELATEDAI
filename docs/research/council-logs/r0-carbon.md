#### `F2-NEW-1` [CRITICAL LOGIC FLAW]: Zombie Reinstatement Under Multi-Step `SUPERSEDE` ($v_1 \to v_2 \to v_3$)
- **Exact Evidence:** [iq04_temporal_evidence.py:600](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/iq04_temporal_evidence.py#L600) (`EK5 v1`), [iq04_temporal_evidence.py:831](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/iq04_temporal_evidence.py#L831) (`compute_well_founded_eligibility`), [iq04_temporal_evidence.py:887](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/iq04_temporal_evidence.py#L887) (`IncrementalEvidenceStore.apply_mutation`), and [run_flagship2_unified_zero_shortcut_and_locomo.py:327](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/scripts/run_flagship2_unified_zero_shortcut_and_locomo.py#L327).
- **Mathematical Proof & Executable Counterexample:** All three implementations collapse `REFUTE` and `SUPERSEDE` into a single Dung attack relation:
  $$\text{attackers}[v] = \{ u \mid (u \xrightarrow{\text{REFUTE}\mid\text{SUPERSEDE}} v) \}$$
  In Dung's abstract argumentation, attack is **anti-monotonic (self-defeating)**: if $e_3$ attacks $e_2$ and $e_2$ attacks $e_1$, defeating $e_2$ *reinstates* $e_1$. That is valid for epistemic falsification (`REFUTE`: "retraction $e_2$ was a false alarm"), **but catastrophic for temporal version updates (`SUPERSEDE`)**!
  - Consider a routine 2-update sequence: $e_1 = \texttt{12bar}$ ($t=1$, with derived notes $e_{1,a}, e_{1,b}$), updated by $e_2 = \texttt{24bar}$ ($t=5$, `SUPERSEDE(e2, e1)`), updated again by $e_3 = \texttt{36bar}$ ($t=10$, `SUPERSEDE(e3, e2)`).
  - Executed directly against `HEAD` `IncrementalEvidenceStore` and `compute_well_founded_eligibility`:
    - `e3` = `ADMIT` $\implies$ `e2` = `AUDIT_ONLY` $\implies$ **`e1` (`12bar`) and `e1_a`, `e1_b` are ZOMBIE-REINSTATED to `ADMIT`!**
    - `evaluate_arm_on_query("C3_ordinary_bitemporal_tms", ...)` immediately selects stale **`12bar`** (`gold = 36bar`, `is_stale_or_false = True`), and in `C4_v2_iq04_ek5_wfs` ([run_flagship2_unified_zero_shortcut_and_locomo.py:327-342](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/scripts/run_flagship2_unified_zero_shortcut_and_locomo.py#L327-L342)), `retracted_tx` only records `dst_id` of `ADMIT -> AUDIT_ONLY` edges (`24bar`), leaving `12bar` un-suppressed so its zombie echoes outvote `36bar`!
  - Why missed previously: Every synthetic lifecycle in [iq04_temporal_evidence.py:215-495](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/iq04_temporal_evidence.py#L215-L495) and [run_flagship2_unified_zero_shortcut_and_locomo.py:168-232](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/scripts/run_flagship2_unified_zero_shortcut_and_locomo.py#L168-L232) only ever tested **1-step** supersession ($v_{\text{old}} \to v_{\text{new}}$)!
- **Exact Fix (Major Theoretical Upgrade for Whitepaper):** Separate **epistemic validity (`REFUTE`)** from **temporal currency (`SUPERSEDE`)** in a two-stage / 4-state semantics:
  1. Compute grounded *validity* (`VALID` | `REFUTED` | `CONTESTED`) purely over `REFUTE` attacks and `DERIVES_FROM`/`COPY_OF` dependencies (so refuting an erroneous update $e_2$ via `REFUTE(e3, e2)` marks $e_2$ `REFUTED`, stripping $e_2$'s superseding force and cleanly reinstating $e_1$!).
  2. Any `VALID` event $u$ (even if itself later superseded by $w$!) retains transitive `SUPERSEDE` force over $v$ (`u --SUPERSEDE--> v` demotes $v$ to `SUPERSEDED` $\subset$ `AUDIT_ONLY`). Thus $e_1 \xleftarrow{\text{SUP}} e_2 \xleftarrow{\text{SUP}} e_3$ yields $e_3 = \texttt{ADMIT}$, $e_2 = \texttt{AUDIT\_ONLY (SUPERSEDED)}$, $e_1 = \texttt{AUDIT\_ONLY (SUPERSEDED)}$!

#### `F2-NEW-2` [THEORETICAL MISLABELING]: `_wfs_propagate_local` Computes Fitting's 3-Valued Kripke-Kleene Semantics, NOT Well-Founded Semantics
- **Exact Evidence:** [iq04_temporal_evidence.py:721-805](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/iq04_temporal_evidence.py#L721-L805) and [tests/test_iq04_temporal_evidence.py:135-167](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/tests/test_iq04_temporal_evidence.py#L135-L167).
- **Mathematical Proof & Counterexample:** Van Gelder, Ross & Schlipf's Well-Founded Semantics (JACM 1991) assigns **FALSE (`AUDIT_ONLY`)** to every **unfounded positive dependency cycle** (via the Greatest Unfounded Set operator). By contrast, `_wfs_propagate_local` only propagates `ADMIT` when `non_f_att[v] == 0 and non_t_dep[v] == 0` and `AUDIT_ONLY` when an attacker is `ADMIT` or a dependency is `AUDIT_ONLY`, assigning all remaining nodes `CONTESTED` ([iq04_temporal_evidence.py:802-804](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/iq04_temporal_evidence.py#L802-L804)). That is **Fitting's (1985) Kripke-Kleene 3-valued least fixed point**!
  - **Executable Counterexample:** Let $A \xleftrightarrow{\text{DERIVES\_FROM}} B$ (two hallucinating agent summaries citing only each other) with $A \xrightarrow{\text{REFUTE}} C$ (attacking a grounded fact $C$). `_wfs_propagate_local` returns `{'A': 'CONTESTED', 'B': 'CONTESTED', 'C': 'CONTESTED'}`—allowing an ungrounded circular derivation loop to poison grounded fact $C$! Under true WFS, $\{A, B\}$ is an unfounded set $\implies A = B = \texttt{AUDIT\_ONLY} \implies C = \texttt{ADMIT}$.
  - Note why the 1,000-graph fuzzer ([run_flagship2_ek5_v2_million_scale.py:50-95](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/scripts/run_flagship2_ek5_v2_million_scale.py#L50-L95)) reported `1000/1000` parity: `compute_well_founded_eligibility` ([iq04_temporal_evidence.py:838](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/iq04_temporal_evidence.py#L838)) calls the exact same `_wfs_propagate_local` helper, verifying incremental-vs-batch Kripke-Kleene parity rather than independent WFS parity! Also note that `EK5 v1` ([iq04_temporal_evidence.py:609-641](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/iq04_temporal_evidence.py#L609-L641)) treated unrefuted `DERIVES_FROM` cycles (`missing_edge_and_cycle_stress`, [iq04_temporal_evidence.py:469-472](file:///D:/GITHUB/CHELATEDAI-STAGE0-NIGHT1/iq04_temporal_evidence.py#L469-L472)) as `ADMIT`, creating an undocumented semantic change between `EK5 v1` and `EK5 v2`.
- **Exact Fix:** Either (a) add linear-time unfounded-set detection on unresolved `dirty` nodes (any strongly connected component of `deps_of` with no `ADMIT`-grounded support path is `AUDIT_ONLY`, not `CONTESTED`) and test against an independent textbook alternating-fixpoint WFS oracle in `tests/`, or (b) explicitly define the logic as **3-Valued Kripke-Kleene Argumentation Semantics** if circular derivations are intentionally treated as `CONTESTED`. (Option (a) is strictly stronger and defends against circular agent hallucinations.)
