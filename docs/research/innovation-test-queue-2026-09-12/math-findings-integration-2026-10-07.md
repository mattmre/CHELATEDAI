## Operator details that the future tests must preserve

The elementary same-input bound is

\[
\|E_\alpha(h)-E_{\hat\alpha}(h)\|_2
\le \|U\|_2\|\alpha-\hat\alpha\|_\infty\|V^*h\|_2.
\]

It assumes a certified coefficient-error bound and the same input. With state divergence, additionally control the relevant update's Lipschitz factor and injected coefficient error at each step, plus every cache/RNG transition included in the contract. A learned confidence score alone is insufficient. Greedy-token equality requires a certified downstream/logit bound and reference margin; exact stochastic output needs its own distribution-preserving verifier. Include the work needed to obtain reference values in the cost comparison.

The current [LowRankAffineAdapter](../../../chelation_adapter.py) computes a row-vector affine correction and then normalizes it. Bias cancels between candidates only if it is identical. A pre-normalization linear certificate does not certify the returned normalized output. The true normalization implementation and epsilon branch must be included, with a proved bound or refusal around insufficient output-norm margins. The current [AdapterRouter](../../../adapter_router.py) uses hard top-one centroid selection; it is a control, not an implemented virtual-mixture router. [EvidenceDAG](../../../evidence_dag.py) is structural, not an already implemented linear diffusion operator.

For fixed `A`, use `||p(A)|| <= (1+sqrt(2)) max_{z in W(A)} |p(z)|` only with a valid outer numerical-range enclosure and its arithmetic budget. Sampling points cannot certify an outer enclosure. Fixed eigenvalues cannot certify switching products. For codebooks, distinguish aperiodic from circular autocorrelation, single-code sidelobes from cross-code coherence, and real binary from complex-phase constructions.
